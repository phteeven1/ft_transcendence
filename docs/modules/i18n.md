# Web Minor — i18n (3 languages)

**Points:** 1 · **Category:** Web (Accessibility)

## Summary

Dicteé supports **English, German, and French** across the full user interface. A flag switcher in the top bar lets users change language; the choice persists in `localStorage` and a `NEXT_LOCALE` cookie. All user-facing copy lives in editable JSON message files and is rendered via **next-intl**.

## Languages

| Code | Language | Flag asset |
|------|----------|------------|
| `en` | English | `/flags/gb.svg` |
| `de` | Deutsch | `/flags/de.svg` |
| `fr` | Français | `/flags/fr.svg` |

## Architecture

```
FlagMenu → LanguageProvider (localStorage + cookie)
         → I18nProvider (next-intl, dynamic message load)
         → useTranslations() in every page/component
```

| File | Role |
|------|------|
| `apps/frontend/messages/{en,de,fr}.json` | All UI strings, namespaced by feature |
| `apps/frontend/i18n/request.ts` | Server locale from `NEXT_LOCALE` cookie |
| `apps/frontend/app/context/language-context.tsx` | Locale persistence + `useSetLocale()` |
| `apps/frontend/app/components/flag-menu.tsx` | Language switcher UI |
| `apps/frontend/app/components/i18n-provider.tsx` | Client-side message reload on switch |

Message namespaces: `common`, `nav`, `home`, `auth`, `invitation`, `dashboard`, `group`, `chat`, `players`, `vocabulary`, `games`, `session`, `legal`, `errors`.

Vocabulary content (word lists, game clues) is **not** translated — only app chrome.

## Demo steps

1. Open **home** (`/`) — note English copy
2. Click the **flag** in the top bar → select **Deutsch** — all visible text switches to German (nav, hero, footer)
3. Navigate to **Dashboard** (sign in if needed) — group tiles and settings modal are German
4. Open **Manage Group** → **Group Chat** tab — filter chips and log sentences are German
5. Switch to **Français** on **Privacy Policy** (`/privacy`) — full legal text is French
6. **Refresh the page** — language stays French (persistence)
7. Inspect `<html lang="fr">` in DevTools

## Eval talking points

- “We use **next-intl** with JSON message catalogs — easy for non-developers to edit translations.”
- “Language persists in **localStorage** (documented in Privacy Policy) and syncs a cookie for SSR.”
- “Group chat log events use **rich text interpolation** so names stay styled inside translated sentences.”
- “Legal pages (Privacy + Terms) are fully translated in all three languages.”

## Adding or editing translations

1. Add the key to `messages/en.json` (source of truth)
2. Mirror the key in `messages/de.json` and `messages/fr.json`
3. In the component: `const t = useTranslations('namespace');` then `t('key')`

## Known limitations

- Backend API error messages remain English; frontend maps common errors via the `errors` namespace where wired
- Vocabulary import language picker (fr/en/de/es/…) is for **content** languages, separate from UI locale
